# Nirupma Portfolio

Portfolio website for Nirupma Singh, built with React and Create React App.

## Run locally

```bash
npm ci
npm start
```

## Production build

```bash
npm run build
```

The production files are generated in `build/`. Deploy that folder to Netlify, or connect this repository to Netlify for continuous deployment.

This folder is an independent Git repository with no remote configured yet. Add Nirupma's GitHub repository as `origin` once it is ready.
